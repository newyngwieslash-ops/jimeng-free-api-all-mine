# Seedance 视频生成能力与第三方应用接入文档

> 适用服务：`jimeng-free-api-all-mine`（豆包多账号无水印通道 + 即梦多账号通道）  
> 默认本地地址：`http://localhost:8000`（由 `configs/dev/service.yml` 配置，双击或运行 `restart.bat` 一键启动）

---

## 1. 当前项目支持的 Seedance 视频全集

本项目同时打通了 **豆包网页版（`doubao`）** 与 **即梦网页版（`jimeng`）** 两条 Seedance 通道，通过模型 ID 前缀自动路由到对应账号池：

### 1.1 两条通道核心能力对比

| 维度 | 豆包通道（`doubao-seedance-*`，主力推荐） | 即梦通道（`jimeng-video-seedance-*`，首尾帧补充） |
| :--- | :--- | :--- |
| **账号成本** | 普通豆包号每日有免费次数，多号自动轮询接力 | 消耗即梦账号积分，支持多号轮询 |
| **水印状态** | **100% 原生无水印**（自动解密 `fallback_api` `qAAB` 24Mbps H.264 母片） | 免费号带官方水印；VIP 账号模型无水印 |
| **防盗链与播放** | **服务端自动下载落盘**，返回本地 `/v1/videos/files/doubao_xxx.mp4`（支持 `206 Range` 拖拽，彻底规避海外代理/Referer `403`） | 返回上游 CDN URL（`vlabvod` 等） |
| **文生视频 (T2V)** | 支持（默认带原生立体声音效/配乐） | 支持 |
| **图生视频 (I2V)** | 支持（传 1–2 张参考图，做主体/首帧参考运镜） | 支持（传 1 张为首帧图生视频） |
| **首尾帧精准过渡** | 不区分严格首尾帧槽位（作为参考图附件） | **支持**（`file_paths[0]` = 首帧，`file_paths[1]` = 尾帧） |
| **运行依赖** | 纯 HTTP 直连，无需浏览器 | `2.0` / `2.0-fast` 遇 `4013` 风控时需 Playwright 浏览器通道 |

## 2. 鉴权与多账号容灾机制

所有接口统一使用 HTTP 请求头：

```http
Authorization: Bearer <API_KEY>
```

1. **托管密钥模式（推荐，适合所有外部 App）**  
   登录 `http://localhost:8000` →「API 密钥」生成 `jm_...` 密钥。调用时自动从账号池挑选对应平台（`doubao` 或 `jimeng`）的健康账号；若遇到单号今日免费次数用完（`-2009`）或 Cookie 失效（`-2002`），网关自动将该号置入冷却并无缝切换下一个账号重试，调用方无感知。
2. **无状态直传模式（免建库）**  
   - 豆包多号（用 `||` 分隔完整 Cookie）：`Authorization: Bearer <cookie_1> || <cookie_2>`  
   - 即梦多号（用 `,` 分隔 `sessionid`）：`Authorization: Bearer <sessionid_1>,<sessionid_2>`

## 3. HTTP API 完整接口规范

### 3.1 查询可用视频模型：`GET /v1/models?type=video`

```bash
curl "http://localhost:8000/v1/models?type=video" \
  -H "Authorization: Bearer jm_你的密钥"
```

返回 OpenAI 兼容列表，每项附带 `default_resolution`、`supported_resolutions`、`default_duration`、`supported_durations` 能力元数据。

### 3.2 生成视频（主力接口）：`POST /v1/videos/generations`

> **重要超时约定**：该接口为**同步长连接等待模式**（渲染 + 无水印母片解密 + 本地缓存落盘通常耗时 **45 秒 – 240 秒**）。客户端 **必须将 HTTP 超时设为 `>= 300000 ms`（5–10 分钟）**。

#### A. JSON 请求方式（`application/json`，推荐跨服务调用）

```http
POST /v1/videos/generations HTTP/1.1
Host: localhost:8000
Authorization: Bearer jm_你的密钥
Content-Type: application/json
```

```json
{
  "model": "doubao-seedance-2.0-mini",
  "prompt": "一只橘猫戴着飞行员墨镜骑着复古小摩托穿过夕阳下的海边公路，电影感镜头",
  "ratio": "16:9",
  "duration": 5,
  "resolution": "720p",
  "file_paths": [
    "https://example.com/ref1.jpg"
  ],
  "response_format": "url"
}
```

| 字段 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `model` | `string` | 否 | `jimeng-video-seedance-2.0` | 强烈建议显式传 `doubao-seedance-2.0-mini` 等目标模型 ID |
| `prompt` | `string` | **是** | — | 视频画面与运镜描述词 |
| `ratio` | `string` | 否 | `"16:9"` | 支持 `"16:9"` `"9:16"` `"1:1"` `"4:3"` `"3:4"` `"21:9"` |
| `duration` | `integer` | 否 | `5` | 豆包支持 `5` / `10`；即梦 Seedance 2.0 系列支持 `4`–`15` |
| `resolution` | `string` | 否 | `"720p"` | 豆包固定 `"720p"`；`jimeng-video-seedance-2.0-vip` 可传 `"1080p"` / `"4k"` |
| `file_paths` | `string[]` | 否 | `[]` | 支持公网 `http(s)://` URL、`data:image/png;base64,...` Data URI 或本机绝对路径。不传为文生视频；传 1–2 张为图生视频（即梦通道第 1 张为首帧、第 2 张为尾帧） |
| `response_format` | `string` | 否 | `"url"` | `"url"` 返回可直接播放的本地/CDN 链接；`"b64_json"` 直接内联返回 MP4 的 Base64 字符串 |

#### B. Multipart 表单文件上传方式（`multipart/form-data`）

适合直接上传本地图片二进制而不想转 Base64：除上述同名文本字段外，任意文件字段名（如 `image`、`first_frame`、`end_frame`）都会按顺序追加进参考图列表。

#### C. 成功响应格式（HTTP `200`）

```json
{
  "created": 1794733547,
  "data": [
    {
      "url": "http://localhost:8000/v1/videos/files/doubao_9468f12c81fa0ee5.mp4",
      "revised_prompt": "一只橘猫戴着飞行员墨镜骑着复古小摩托穿过夕阳下的海边公路，电影感镜头"
    }
  ]
}
```

> 当 `response_format` 为 `"b64_json"` 时，`data[0]` 结构为 `{ "b64_json": "<MP4 Base64>", "revised_prompt": "..." }`。

#### D. 错误响应格式与错误码（务必在客户端校验！）

> **调用方必读坑点**：本项目沿用 `jimeng-free-api` 框架约定，业务异常默认返回 **HTTP `200`**，通过顶层 `code`（负数）标识失败，**没有 `data` 数组**！客户端判断成功必须同时检查 `res.ok && Array.isArray(body.data) && body.data[0]?.url`（或判断 `typeof body.code === "number" && body.code !== 0`）。

```json
{
  "code": -2009,
  "message": "当前豆包账号今日免费视频次数已用完: ..."
}
```

| `code` | 含义 | 网关自动行为 / 调用方处理建议 |
| :---: | :--- | :--- |
| `-2000` | 请求参数非法（如空 `prompt`） | 不切换账号，直接向调用方报错，请检查入参 |
| `-2002` | Cookie / Session 登录态过期 | 账号池自动冷却该号并切换下一账号；全部失效时需在控制台更新 Cookie |
| `-2003` / `-2004` | 参考图 URL 无效或超过 100MB 限制 | 检查图片 URL 可达性与体积 |
| `-2006` | 提示词或参考图触发上游安全审核拦截 | 修改提示词后重试 |
| `-2008` | 视频渲染失败或轮询超时（10 分钟） | 可重试一次 |
| `-2009` | 今日免费次数用完 / 无订阅模型权限 / 即梦积分不足 | 账号池自动切换下一可用账号；免费豆包号请选 `2.0-mini` 或 `2.0-fast` |
| `-2010` | 上游 IP 级风控限流（`710022002` / `710022004`） | 保护账号池不误判失效，稍后重试或切换网络 |

### 3.3 本地无水印视频流读取：`GET /v1/videos/files/:filename`

- 支持标准浏览器 `<video src="...">` 直接播放与 `Range: bytes=...`（HTTP `206 Partial Content`）进度条拖拽。
- 响应头带 `Cache-Control: no-cache` + `ETag` 校验。
- 追加 `?download=1`（如 `http://localhost:8000/v1/videos/files/doubao_xxx.mp4?download=1`）可触发 `Content-Disposition: attachment` 附件下载。
- **反代 / Docker Host 自动适配**：接口会根据请求头 `X-Forwarded-Proto` + `X-Forwarded-Host`（或 `Host`）动态拼接返回的 `url` 域名（例如容器通过 `http://host.docker.internal:8000` 请求，返回的 `url` 前缀也会自动变成 `http://host.docker.internal:8000/v1/videos/files/...`）。

---

### 3.4 OpenAI Chat 兼容多模态入口（备选）：`POST /v1/chat/completions`

仅适用于只支持 Chat Completions 协议的客户端（如通用聊天套壳 UI）：
- `model` 传 `doubao-seedance-2.0-mini` 或 `jimeng-video-seedance-2.0-mini`。
- `messages` 中 `text` 为提示词，`image_url` 为参考图。
- 返回 `choices[0].message.content` 为 Markdown 字符串 `![video](http://.../doubao_xxx.mp4)\n`（不支持显式传 `ratio` / `duration`，固定默认参数）。

## 4. 对接 `open-ai-canvas-flow`（影策插件体系）指南

经核对 `E:\AI_Cloud_Agent_Things\open-ai-canvas-flow\plugin-packages\` 的 `yingce.plugin/v2` 契约，接入时需注意以下 **3 个协议差异点**：

1. **内置插件不能直接硬套**：
   - `open-ai-canvas-flow` 内置的 `seedance-videos-compatible` 请求的是异步 `POST /v1/videos` + `GET /v1/videos/{{taskId}}`；
   - 内置的 `dola-pool` 虽然请求 `POST /v1/videos/generations`，但它传的是 `reference_images` 字段且预期异步轮询 `GET /v1/videos/{{taskId}}`；
   - 本服务当前是**同步返回** `{ created, data: [{ url }] }`，参考图字段名为 `file_paths`。
2. **在 `open-ai-canvas-flow` 中最简零改后端接入方式**：使用 `yingce.plugin/v2` 的同步映射模式（同 `openai-images` 插件的 `"status": "succeeded"`，无需 `poll`），并开启 `"resultEphemeral": true` 让影策后端拿到本地 `/v1/videos/files/...` 后立即自动转存持久化到影策媒体库。
3. **容器网络地址**：若 `open-ai-canvas-flow` 跑在 Docker 容器内，而本服务跑在宿主机 `8000` 端口，`baseUrl` 请填 `http://host.docker.internal:8000`（同机纯本地进程则填 `http://127.0.0.1:8000`），且需确保影策宿主请求超时 `>= 300s`。

## 5. 通用 Node.js / TypeScript 与 Python 调用封装

### 5.1 TypeScript / Node.js（含业务负数错误码完备校验）

```ts
export interface SeedanceVideoOptions {
  model?:
    | "doubao-seedance-2.0-mini"
    | "doubao-seedance-2.0-fast"
    | "doubao-seedance-2.0"
    | "doubao-seedance-2.5"
    | "jimeng-video-seedance-2.5"
    | "jimeng-video-seedance-2.0-mini"
    | "jimeng-video-seedance-2.0-fast"
    | "jimeng-video-seedance-2.0"
    | "jimeng-video-seedance-2.0-vip"
    | string;
  prompt: string;
  ratio?: "16:9" | "9:16" | "1:1" | "4:3" | "3:4" | "21:9";
  duration?: number;        // 豆包: 5 | 10；即梦 2.0: 4..15
  resolution?: "720p" | "1080p" | "4k";
  referenceImages?: string[]; // URL 或 data:image/...;base64,...（最多2张）
  baseUrl?: string;
  apiKey: string;
  timeoutMs?: number;
}

export async function generateSeedanceVideo(opts: SeedanceVideoOptions): Promise<string> {
  const baseUrl = (opts.baseUrl || "http://localhost:8000").replace(/\/+$/, "");
  const res = await fetch(`${baseUrl}/v1/videos/generations`, {
    method: "POST",
    headers: {
      Authorization: `Bearer ${opts.apiKey}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      model: opts.model || "doubao-seedance-2.0-mini",
      prompt: opts.prompt,
      ratio: opts.ratio || "16:9",
      duration: opts.duration ?? 5,
      resolution: opts.resolution || "720p",
      file_paths: (opts.referenceImages || []).filter(Boolean),
    }),
    signal: AbortSignal.timeout(opts.timeoutMs ?? 360_000),
  });

  const body: any = await res.json();
  if (!res.ok || (typeof body?.code === "number" && body.code !== 0)) {
    throw new Error(`Seedance API error (${body?.code ?? res.status}): ${body?.message || res.statusText}`);
  }
  const url = body?.data?.[0]?.url;
  if (!url) throw new Error(`Seedance API returned empty video URL: ${JSON.stringify(body)}`);
  return url;
}
```

### 5.2 Python (`httpx` / `requests`)

```python
import requests

def generate_seedance_video(
    prompt: str,
    api_key: str,
    model: str = "doubao-seedance-2.0-mini",
    ratio: str = "16:9",
    duration: int = 5,
    reference_images: list[str] | None = None,
    base_url: str = "http://localhost:8000",
) -> str:
    resp = requests.post(
        f"{base_url.rstrip('/')}/v1/videos/generations",
        headers={"Authorization": f"Bearer {api_key}"},
        json={
            "model": model,
            "prompt": prompt,
            "ratio": ratio,
            "duration": duration,
            "file_paths": reference_images or [],
        },
        timeout=360,
    )
    resp.raise_for_status()
    body = resp.json()
    if isinstance(body.get("code"), int) and body["code"] != 0:
        raise RuntimeError(f"Seedance error {body['code']}: {body.get('message')}")
    return body["data"][0]["url"]
```
