## 0. 豆包网页版多账号 Seedance 视频（推荐 · 纯 HTTP 免浏览器直连 · 自动去水印）

### 添加多个豆包账号
1. 确保启动服务时配置了账号池加密密钥：`JIMENG_ACCOUNT_POOL_KEY=<任意非空密钥字符串>`。
2. 浏览器登录 `https://www.doubao.com/chat/` → 按 `F12` 打开「网络 (Network)」面板 → 任选一条 `www.doubao.com` 请求 → 复制请求头中的完整 `Cookie`（建议含 `sessionid`、`ttwid`、`passport_csrf_token`）。
3. 进入控制台「账号池」页签 → 平台选择 **豆包网页版 (www.doubao.com)** → 粘贴 Cookie 保存。添加多个账号后，服务自动轮询并在单号当日免费次数耗尽或登录过期时自动冷却、无缝切换到下一可用豆包账号重试。

### 豆包 Seedance 模型列表

| 模型 ID | 上游映射 | 时长 | 比例 | 说明 |
|---|---|---|---|---|
| `doubao-seedance-2.0-mini` | `seedance_v2.0_mini` | `5` / `10` 秒 | `16:9` `9:16` `1:1` `4:3` `3:4` `21:9` | 日常生成，**每日免费额度可用（默认推荐）** |
| `doubao-seedance-2.0-fast` | `seedance_v2.0` | `5` / `10` 秒 | 同上 | 快速出片，**每日免费额度可用** |
| `doubao-seedance-2.0` | `seedance_v2.0_std` | `5` / `10` 秒 | 同上 | 进阶画面（2倍消耗，需豆包订阅账号） |
| `doubao-seedance-2.5` | `seedance_v2.5` | `5` / `10` 秒 | 同上 | 旗舰版（5倍消耗，需豆包订阅账号） |

### 豆包视频 API 调用示例（文生视频 & 图生视频）

```bash
curl http://localhost:8001/v1/videos/generations \
  -H "Authorization: Bearer <API_KEY>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "doubao-seedance-2.0-mini",
    "prompt": "镜头缓缓推进，海浪拍打礁石，逆光，电影感",
    "ratio": "16:9",
    "duration": 10
  }'
```

- **图生视频**：传入 `"file_paths": ["https://example.com/frame.png"]`（也支持 `data:image/png;base64,...` 或 multipart 上传文件）。
- **直传多账号凭据**：若不使用托管 `jm_...` Key，也可直接在请求头传 `Authorization: Bearer <cookie1> || <cookie2>`（用 `||` 分隔多个完整 Cookie）。

## 3. 调用方式

### 方式一：OpenAI 兼容接口 `/v1/chat/completions`（多模态消息）

图片放在 `image_url` 里，**第 1 张 → 首帧，第 2 张 → 尾帧**（`chat.ts:180` → `videos.ts:463`）：

```bash
curl http://localhost:8001/v1/chat/completions \
  -H "Authorization: Bearer <API_KEY>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "jimeng-video-seedance-2.5",
    "messages": [{
      "role": "user",
      "content": [
        { "type": "text", "text": "镜头缓缓推进，女孩转头微笑，电影感" },
        { "type": "image_url", "image_url": { "url": "https://example.com/first.jpg" } },
        { "type": "image_url", "image_url": { "url": "https://example.com/last.jpg" } }
      ]
    }]
  }'
```

- 也支持 base64：`"url": "data:image/jpeg;base64,..."`
- 返回 chat completion，视频地址在 `choices[0].message.content` 中包成 `![video](url)` 的 Markdown
- 限制：chat 路径固定 720p、默认 5s 时长，无法传 ratio/duration

### 方式二：专用视频接口 `/v1/videos/generations`（参数更全，推荐程序调用）

```bash
curl http://localhost:8001/v1/videos/generations \
  -H "Authorization: Bearer <API_KEY>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "jimeng-video-seedance-2.5",
    "prompt": "镜头缓缓推进，女孩转头微笑，电影感",
    "ratio": "16:9",
    "resolution": "720p",
    "duration": 10,
    "file_paths": ["https://example.com/first.jpg", "https://example.com/last.jpg"],
    "response_format": "url"
  }'
```

参数说明：

| 参数 | 说明 |
|---|---|
| `model` | 视频模型 ID，见第 1 节 |
| `prompt` | 生成提示词 |
| `ratio` | 画面比例，如 `16:9`（默认 `16:9`） |
| `resolution` | 分辨率，需在该模型 `supported_resolutions` 内，否则自动回落到默认值 |
| `duration` | 时长（秒），Seedance 2.x 支持 **4–15 秒**整数（`models.ts:29`） |
| `file_paths` | 参考图数组：第 1 张 → 首帧，第 2 张 → 尾帧；只传 1 张即纯图生视频；不传即文生视频 |
| `response_format` | `url`（默认）或 `b64_json`（返回 base64） |

返回结构：

```json
{
  "created": 1760000000,
  "data": [{ "url": "https://...", "revised_prompt": "..." }]
}
```

## 4. 在其他项目中的封装示例（JS）

```js
async function genVideo(prompt, firstFrameUrl, lastFrameUrl) {
  const res = await fetch("http://localhost:8001/v1/videos/generations", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.JIMENG_API_KEY}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      model: "jimeng-video-seedance-2.5",
      prompt,
      duration: 10,
      file_paths: [firstFrameUrl, lastFrameUrl].filter(Boolean),
    }),
  });
  const data = await res.json();
  return data.data[0].url; // 生成是同步等待的，客户端超时建议设 ≥5 分钟
}
```

## 5. 注意事项

1. **同步阻塞**：视频生成约 1–5 分钟，HTTP 请求会一直挂到出片才返回，调用方超时要设够长；Web 前端直调建议走服务端中转 + 轮询/异步任务。
2. **风控**：Seedance 2.0/2.0-fast 纯服务端请求会被上游风控拦截（`ret=4013`）。本容器已预装 Chromium、默认 `auto` 模式会自动走浏览器签名重试，无需额外配置。2.5 若同样被拦也会走该通道。
3. **积分**：这些链路消耗账号积分，积分不足时上游返回 1006（服务转 `-2009`）。多账号轮询可分摊积分消耗。
4. **参考图格式**：`file_paths` 传本地文件路径仅对**容器内路径**有效（路由还支持 multipart `files` 上传，见 `routes/videos.ts`）。跨项目调用最省事的方式是传公网 URL 或 base64。
